# 拡張性の要件（U2 コース探索）

要件定義書（`../../../inception/requirements-analysis/requirements.md`）の NFR7（データアクセスの差し替え）を、U2 の探索に当てはめる。想定する規模は U1 と同じ（`../../u1-purchase-skeleton/nfr-requirements/scalability-requirements.md`）。

## 要件

| ID | 要件 | 確かめ方 |
| --- | --- | --- |
| NFR7.1 | 絞り込みと並べ替えは CourseCatalog の純粋関数として書き、データストアに依存しない（ADR-001・ADR-006）。将来 PostgreSQL の検索に置き換えるときは、同じ条件（SearchCondition）を受け取る別の実装に差し替えられる形にする | コードレビュー |
| NFR7.2 | 絞り込みと並べ替えのテストは、データストアを使わず、固定のコース・日程・発行済み数を返す関数を渡して動かす | CourseCatalog の自動テスト |
| NFR7.3 | 将来 PostgreSQL に移すときの注意（キーワードの正規化を検索用の列に持たせる、よみがなに索引を張る、期間は開催開始日の索引で絞る）を、探索の関数のコメントに書いておく | コードレビュー |
| NFR7.4 | 画面の探索条件の状態と URL の変換は、U3 以降で条件を足しても既存の項目を変えずに足せる形にする | コードレビュー |

## 対象外

- 全文検索の仕組み（形態素解析・あいまい検索・検索語の候補の表示）は扱わない。
