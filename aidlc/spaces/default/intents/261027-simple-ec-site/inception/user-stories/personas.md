# ペルソナ

## P1. 高橋 遥（たかはし はるか）— AI 駆動開発に初めて挑戦する事業企画担当

| 項目 | 内容 |
| --- | --- |
| 所属・役割 | 契約企業「株式会社サンプル商事」の事業企画部。社内向け業務改善の企画を担当して 6 年目（34 歳） |
| 背景 | プログラミングの実務経験はない。表計算ソフトの関数や簡単なマクロは使える。コーディングエージェントが社内でも話題になり、「自分で小さな業務ツールを作れるかもしれない」と考え始めた |
| 目的（Goals） | ・AI 駆動開発の最初の一歩として、半日程度（数時間）で全体像をつかめる入門研修を受けたい<br>・業務の繁忙期を避け、自分の予定に合う日程で受けたい<br>・会社から付与された研修予算の範囲で、計画的に受講したい |
| 困りごと（Pain Points） | ・専門用語が多い研修一覧から、初心者向けのものを見分けるのに時間がかかる<br>・良さそうな研修を見つけても、行ける日程が満席だったと最後に分かるとがっかりする<br>・予算の残りがいくらで、買ったらいくら残るのかが分かりにくいと、申し込みをためらう |
| IT への慣れ | 中（業務アプリは日常的に使うが、開発の知識はない） |
| 利用頻度 | 年に数回（研修を探すとき、まとめて利用する） |
| 研修予算 | 年間 60,000 pt（初期データ上の想定） |
| 利用環境 | 社内ポータルから PC のブラウザでアクセスする。ログインは社内ポータル側で済んでいる |

### このペルソナにとっての「優れた体験」

- 「AI」「入門」などの言葉や、カテゴリ・空席・期間で絞り込み、自分に合うコースへ数回の操作でたどり着ける
- 日程を選ぶ前に、空席の有無と選べない理由がひと目で分かる
- 購入前に「今の残高」「受講料」「購入後の残高」を確かめられ、安心して確定できる
- 購入後すぐに e チケットを確認でき、あとから一覧で見返せる

### 受講形式についての補足

受講形式はオンライン（ライブ配信）または会場とし、開催日程と定員がある研修を扱う（要件定義書 FR3）。録画を視聴するだけの動画講座は今回扱わない（`user-stories-questions.md` の Q1 と確認時の合意）。

## ペルソナの優先度と関係

本プロジェクトのペルソナは P1 の 1 人のみ（`user-stories-questions.md` の Q1）。すべてのストーリーは P1 の視点で書く。契約が終了した企業の従業員が購入できないこと（要件 FR1.3）は、P1 が所属企業の契約状態の変化に直面した場面としてストーリー化する（US5.1）。
