# ユーザーストーリー

ストーリーは購入体験の流れ（ジャーニー）に沿って分割している。

## エピック E1: 商品を探す

### US-01 商品一覧を見る
**ペルソナ**: P1, P2
**ストーリー**: 買い物客として、トップページで商品の一覧を見たい。何が買えるのかすぐに把握するためだ。

受け入れ基準:
- [ ] トップページに全商品がカード形式で表示される
- [ ] 各カードに商品名・価格（税込）・カテゴリ・評価・在庫状況が表示される
- [ ] 読み込み中はスケルトンが表示される
- [ ] 在庫が 5 個以下の商品には「残りわずか」、0 個の商品には「在庫切れ」が表示される

### US-02 キーワードで検索する
**ペルソナ**: P1
**ストーリー**: 買い物客として、キーワードを入力して商品を絞り込みたい。目的の商品にすぐたどり着くためだ。

受け入れ基準:
- [ ] 入力に追従して一覧が絞り込まれる（商品名・説明が対象）
- [ ] 該当なしの場合は、条件をリセットするボタン付きの空状態が表示される
- [ ] 検索条件は URL に反映され、共有・再読み込みしても保持される

### US-03 カテゴリで絞り込み、並べ替える
**ペルソナ**: P2
**ストーリー**: 比較検討する買い物客として、カテゴリで絞り込み、価格や人気で並べ替えたい。効率よく比較するためだ。

受け入れ基準:
- [ ] カテゴリのチップを選ぶと該当商品だけが表示される
- [ ] 「おすすめ順／価格の安い順／価格の高い順／評価の高い順」で並べ替えられる
- [ ] 表示件数が表示される

### US-04 商品の詳細を見る
**ペルソナ**: P2
**ストーリー**: 買い物客として、商品の詳細を確認したい。購入して問題ないか判断するためだ。

受け入れ基準:
- [ ] 商品名・説明・価格・評価・在庫数が表示される
- [ ] 存在しない商品 ID の場合は「商品が見つかりません」と一覧への導線が表示される

## エピック E2: カートに入れる

### US-05 カートに追加する
**ペルソナ**: P1, P2
**ストーリー**: 買い物客として、数量を指定して商品をカートに追加したい。

受け入れ基準:
- [ ] 一覧・詳細の両方からカートに追加できる
- [ ] 追加するとトーストで通知され、ヘッダーのカートバッジが更新される
- [ ] 在庫数を超える数量は追加できない。在庫切れの商品はボタンが無効になる

### US-06 カートを編集する
**ペルソナ**: P2
**ストーリー**: 買い物客として、カートの数量を変更したり商品を削除したりしたい。

受け入れ基準:
- [ ] 数量を ± ボタンで変更でき、合計が即時に再計算される
- [ ] 削除ボタンで商品をカートから除ける
- [ ] カートが空の場合は、買い物を続けるための導線付きの空状態が表示される
- [ ] 再読み込みしてもカートの内容が保持される

### US-07 送料と合計を把握する
**ペルソナ**: P2
**ストーリー**: 買い物客として、送料無料まであといくらかを知りたい。まとめ買いの判断をするためだ。

受け入れ基準:
- [ ] 小計・送料・合計が表示される
- [ ] 5,000 円未満の場合は「あと ○○ 円で送料無料」とプログレスバーが表示される
- [ ] 5,000 円以上の場合は送料が 0 円になり、送料無料である旨が表示される

## エピック E3: 購入する

### US-08 配送先と支払方法を入力する
**ペルソナ**: P1, P3
**ストーリー**: 買い物客として、会員登録せずに配送先と支払方法を入力したい。

受け入れ基準:
- [ ] 氏名・メールアドレス・郵便番号・住所・電話番号・支払方法を入力できる
- [ ] 各項目は入力欄からフォーカスが外れた時点で検証され、項目の直下にエラーが表示される
- [ ] 送信時にエラーがあれば最初のエラー項目にフォーカスが移る
- [ ] すべての項目にラベルがあり、キーボードだけで入力・送信できる
- [ ] 注文内容の要約（商品・合計）が同じ画面に表示される

### US-09 注文を確定する
**ペルソナ**: P1, P2
**ストーリー**: 買い物客として、注文を確定して注文番号を受け取りたい。

受け入れ基準:
- [ ] 注文確定中はボタンが無効化され、二重送信されない
- [ ] 成功すると注文番号・合計・配送先が表示された完了画面へ遷移し、カートが空になる
- [ ] 在庫不足などでサーバーがエラーを返した場合、理由がわかるメッセージが表示され、カートは保持される
- [ ] 合計金額はサーバー側で再計算された値が採用される
