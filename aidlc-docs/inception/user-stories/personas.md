# ペルソナ

## P1: 忙しい会社員「佐藤 美咲」（32 歳）

- 通勤中にスマートフォンで買い物をする
- 欲しいものが決まっていることが多く、**すぐに見つけてすぐに買いたい**
- 不満: 会員登録の強制、入力フォームのエラーが送信後にまとめて出ること

## P2: じっくり比較派「田中 健一」（45 歳）

- 自宅の PC で、価格や評価を比較しながら購入する
- 送料を気にして**送料無料ラインまでまとめ買い**する
- 不満: 合計金額が最後まで分からないこと、在庫切れに注文後に気づくこと

## P3: キーボード操作中心のユーザー「山本 陽菜」（28 歳）

- 手の負担を減らすため、マウスを使わずキーボードで操作する
- スクリーンリーダーを併用することがある
- 不満: フォーカスが見えない、ボタンにラベルがない
