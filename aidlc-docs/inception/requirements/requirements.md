# 要件定義書

## 1. 背景と目的

「優れたユーザー体験を備えたシンプルな EC サイト」を新規に構築する。
今回はワークショップのスコープとして、**ローカル環境で動作検証できる状態**をゴールとし、クラウドへのデプロイは行わない。

## 2. 意図分析（Intent Analysis）

| 観点 | 分析結果 |
| --- | --- |
| リクエスト種別 | 新規プロジェクト（Greenfield） |
| 明確さ | 中程度 —「シンプル」「優れた UX」の解釈が必要 |
| スコープ | 単一アプリケーション（フロントエンド＋API） |
| 複雑度 | 中（認証・決済連携は対象外とすることで単純化） |
| 深さ | Standard |

## 3. 前提と判断（質問への回答として採用した既定値）

AI-DLC では通常、要件確認の質問ファイルをユーザーに回答してもらうが、本セッションは自律実行のため、以下の既定値を採用した。変更が必要な場合はこの表を更新して再実行する。

| # | 確認事項 | 採用した回答 | 理由 |
| --- | --- | --- | --- |
| Q1 | 取り扱う商材 | 日用雑貨・生活用品（架空の商品 12 点） | 汎用的で画像なしでも表現しやすい |
| Q2 | 会員登録・ログイン | 不要（ゲスト購入のみ） | 「シンプル」を優先。購入までの摩擦を最小化 |
| Q3 | 決済 | 模擬決済（実決済連携なし。代金引換／クレジットカード（ダミー）を選択可） | ローカル検証のみのため |
| Q4 | 管理画面 | 対象外 | スコープ外 |
| Q5 | 在庫管理 | あり（在庫数の表示と注文時の在庫引当） | 実用的な EC の最低限 |
| Q6 | データ永続化 | サーバープロセス内メモリ＋カートはブラウザの localStorage | ローカル検証に十分で外部依存なし |
| Q7 | 対応デバイス | PC・スマートフォン（レスポンシブ） | UX 要件 |
| Q8 | 言語・通貨 | 日本語 / 日本円（税込表示） | ユーザー指示 |
| Q9 | 技術スタック | TypeScript / React + Vite（フロント）、Hono on Node.js（API） | 軽量でローカル起動が容易 |

## 4. 機能要件（FR）

| ID | 要件 | 優先度 |
| --- | --- | --- |
| FR-01 | 商品一覧を表示できる（商品名・価格・カテゴリ・評価・在庫状況） | 必須 |
| FR-02 | キーワードで商品を検索できる（入力に追従してリアルタイム絞り込み） | 必須 |
| FR-03 | カテゴリで商品を絞り込める | 必須 |
| FR-04 | 価格（安い順・高い順）・人気順で並べ替えできる | 必須 |
| FR-05 | 商品詳細（説明・価格・在庫）を表示できる | 必須 |
| FR-06 | 数量を指定してカートに追加できる（在庫数を上限とする） | 必須 |
| FR-07 | カートの数量変更・削除ができる | 必須 |
| FR-08 | カートの内容はページ再読み込み後も保持される | 必須 |
| FR-09 | 小計・送料・合計（税込）を表示する。5,000 円以上で送料無料、未満は 500 円 | 必須 |
| FR-10 | 送料無料までの残額を表示する | 推奨 |
| FR-11 | 購入手続き画面で配送先（氏名・メール・郵便番号・住所・電話番号）と支払方法を入力できる | 必須 |
| FR-12 | 入力値をリアルタイムに検証し、項目ごとにわかりやすいエラーを表示する | 必須 |
| FR-13 | 注文を確定すると注文番号付きの完了画面を表示し、カートを空にする | 必須 |
| FR-14 | 注文確定時にサーバー側で価格の再計算と在庫引当を行い、在庫不足の場合はエラーを返す | 必須 |
| FR-15 | カート追加などの操作結果をトースト通知でフィードバックする | 推奨 |
| FR-16 | ヘッダーにカート内点数のバッジを常時表示する | 必須 |

## 5. 非機能要件（NFR）概要

詳細は `construction/ec-app/nfr-requirements/nfr-requirements.md` を参照。

| ID | 要件 |
| --- | --- |
| NFR-01 | ユーザビリティ: 3 クリック以内で「商品を見つける → カートに入れる → 購入手続きへ進む」が可能 |
| NFR-02 | アクセシビリティ: キーボードのみで操作可能、ラベル・ARIA 属性の付与、十分なコントラスト |
| NFR-03 | レスポンシブ: 360px 幅から PC まで崩れずに表示 |
| NFR-04 | 体感性能: 読み込み中はスケルトン表示、ローカルで API 応答 100ms 以内 |
| NFR-05 | 信頼性: 価格・合計はサーバー側で確定（クライアントの値を信用しない） |
| NFR-06 | 保守性: TypeScript の strict モード、ユニットテスト・E2E テストを整備 |
| NFR-07 | 実行容易性: `npm install` → `npm run dev` の 2 ステップでローカル起動できる |

## 6. スコープ外

- 会員登録・ログイン・マイページ
- 実決済サービスとの連携
- 管理画面（商品登録・受注管理）
- クラウドへのデプロイ、CI/CD、監視
- 永続的なデータベース
